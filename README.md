# LiLiBanque

Addon WoW Forever pour les officiers de La Bande à Li Li. À l'ouverture de la banque de guilde, il relève le journal d'or, le solde, le roster et les objets des onglets visibles. Il ne fait que lire.

## Installation

Dans WowUp, client `_forever_` : *Get Addons → Install from URL* avec l'adresse de ce dépôt.

Ou à la main : extraire le zip de la dernière release dans `_forever_\Interface\AddOns`.

## Commandes

- `/lili` : ouvre la fenêtre
- `/lili scan` : relance un relevé
- `/lili export` : copie le relevé
- `/lili diag` : diagnostic
- `/lili rappel on|off` : active ou désactive le rappel de passage à la banque pour ce personnage
- `/lili reset` : efface les données locales

## Journal d’objets

À la banque de guilde, ouvrez le journal d’objets du jeu pour l’onglet voulu, puis `/lili` → Coffre → Journal d’objets. L’addon conserve localement le dernier relevé des mouvements récents, sans modifier la banque.
